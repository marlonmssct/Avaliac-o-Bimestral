# Avaliação Bimestral

Este repositório contém a estrutura base e a solução para o projeto de **Avaliação Bimestral** em JavaScript.

## Estrutura do Projeto

- `css/styles.css`: Estilos e layout da aplicação.
- `js/main.js`: Lógica principal em JavaScript.
- `assets/`: Imagens e ícones utilizados no projeto.
- `index.html`: Página principal da aplicação.
